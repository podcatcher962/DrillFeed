# 🔬 DrillFeed

> Vertical RSS reader for researchers & geeks — drill deep, read wide.

A clean, native Windows desktop app that brings 15 curated Chinese RSS feeds into one place. No cloud, no account, no tracking. Everything stays local.

## ✨ Features

| 功能 | 说明 |
|------|------|
| 📡 **15 curated feeds** | 36Kr, ITHome, iFanr, LeiFeng, GeekPark, Solidot, InfoQ, 199IT, Xueqiu, SSPai, Appinn, GCores, Jiemian, ToodayLab, Ruan Yifeng |
| 📂 **Category browsing** | 7 categories: Tech Frontier · Digital Tools · Geek & Open Source · Blog & Opinion · Business · Gaming · Finance |
| 🔍 **Instant search** | Full-text search across titles & summaries |
| 📅 **Date filter** | Today / 3 days / 7 days / 30 days |
| ⭐ **Bookmarks** | Save important reads |
| 📤 **Share card** | One-click copy formatted text + link to clipboard |
| 🌐 **Open in browser** | Double-click to read original article |
| ➕ **Custom RSS** | Add any standard RSS/Atom feed |
| 📖 **Unread tracking** | Green dot indicator |

---

## 🚀 Quick Start

1. Download `DrillFeed.exe` from [Releases](https://github.com/podcatcher962/DrillFeed/releases)
2. Double-click — 15 feeds auto-import on first launch
3. Click **⟳ Refresh** to fetch articles
4. Browse, search, bookmark, share

**No installation required. No Python needed.**

---

## 🛠 Tech Stack

- Python 3 + tkinter + SQLite
- Zero pip dependencies
- Windows 10/11
