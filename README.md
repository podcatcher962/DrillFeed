# DrillFeed

A vertical RSS reader for researchers and geeks — drill deep into niche topics.

Built-in 9 curated Chinese RSS feeds across tech, open source, and finance. Add your own feeds, bookmark important articles, full-text search.

## Features

- 📡 One-click import 9 curated feeds (36Kr / ITHome / iFanr / LeiFeng / GeekPark / Solidot / InfoQ / 199IT / Xueqiu)
- 🔄 Category-based feed management with background refresh
- 🔍 Full-text search across titles and summaries
- ⭐ Bookmark important articles
- 🌐 Open original article in browser
- ➕ Custom RSS/Atom feed support
- 📖 Read/unread tracking with green highlights

## Usage

1. Double-click `DrillFeed.exe` or run `python drillfeed.py`
2. Click **📋 Presets** to import 9 feeds
3. Click **⟳ Refresh** to fetch articles
4. Click feed names on left to browse articles
5. 🔍 Search, ⭐ Bookmark, 🌐 Open original

## Custom Feeds

Click **+ button**, paste any standard RSS 2.0 or Atom feed URL.

## Tech Stack

- Python 3 + tkinter + SQLite
- Zero external dependencies
- Windows 10/11 compatible
